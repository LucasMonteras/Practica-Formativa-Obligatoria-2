Necesito que hagas lo siguiente:

### 2. Crear o completar la portada final

Dentro de la carpeta `Portada/`, generá una portada principal profesional, clara y responsive.

La portada debe incluir:

* título principal: **Práctica Formativa Obligatoria 2**
* subtítulo: **Prompt Engineering en Agentes de IA**
* breve explicación de que el proyecto compara resultados generados por dos agentes distintos a partir del mismo prompt
* mi nombre como autor de la entrega
* tres accesos directos claramente visibles:

#### Acceso 1

Texto: **Ver Prompt Utilizado**

#### Acceso 2

Texto: **Ver Landing generada por Codex**
Además, debe indicar visualmente:

* agente: Codex
* modelo: si puede inferirse automáticamente, mostrarlo; si no, mostrar “modelo no identificado”

#### Acceso 3

Texto: **Ver Landing generada por OpenCode**
Además, debe indicar visualmente:

* agente: OpenCode

### 3. Guardar el prompt exacto

Dentro de la carpeta `Prompt/`, crear o sobrescribir un archivo:

* `prompt.txt`

Ese archivo debe contener exactamente este texto completo del prompt que estoy escribiendo ahora mismo.
Si no podés autoextraer con precisión el texto completo del mensaje actual, entonces creá el archivo con un encabezado claro y una nota indicando que el usuario debe pegar manualmente el prompt exacto utilizado para cumplir la consigna.

### 4. Garantizar navegación funcional

La portada debe enlazar correctamente hacia:

* el archivo de texto del prompt
* la landing de `Codex/`
* la landing de `OpenCode/`

Usá rutas relativas correctas.

### 5. Preparar el proyecto para un único deploy

Quiero que la estructura quede lista para que después yo pueda:

* subir todo a un único repositorio de GitHub
* hacer un único deploy en Vercel
* y que la entrada principal del proyecto sea la portada

Necesito que el proyecto final arranque desde la **portada**.

Elegí la mejor estrategia para esto, por ejemplo:

* creando un `index.html` en la raíz que redirija o enlace a `Portada/`

Tomá la decisión más clara, mantenible y profesional.
